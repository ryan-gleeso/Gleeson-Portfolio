Project Atlas

A desk-integrated home lab bringing robotics, embedded electronics and a Raspberry Pi-powered control interface into one system.

Raspberry Pi 5 ESP32 Python PySide6

Overview

Project Atlas is my ongoing platform for building and connecting projects around my desk. The Raspberry Pi provides the central interface, while embedded controllers operate individual mechanisms.

The broader vision includes a robot arm, device troubleshooting tools and other home automation modules.

What I've built so far

  • Raspberry Pi control interface on a secondary display.
  • I²C rotary encoder navigation.
  • Stepper-driven motorised screen lift.
  • Separate 12 V and 5 V power rails for the lift and display.

Next steps

Continue integrating the hardware modules and documenting the electrical design, software and mechanical components.
