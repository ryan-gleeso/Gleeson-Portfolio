DART

A simulated drone robotics project developed as part of Robotics Studio 1 at UTS.

ROS 2 Gazebo LiDAR Team project

Overview

Our team is developing a drone system in simulation, bringing together sensing, perception, control and a user interface.

My contribution

My work focuses on LiDAR sensing and how its information can be used within the wider drone system.

Tools and integration

  • ROS 2 for communication between system components.
  • Gazebo for simulation and testing.
  • LiDAR data for perception-related work.
  • Git for coordinating development with the team.
