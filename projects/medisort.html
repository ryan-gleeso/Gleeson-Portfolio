MediSort

A multi-robot pill sorting system developed in simulation. It coordinates pill pickup, robot-to-robot handoff and deposit through a state machine and resolved motion rate control.

Python Swift simulation Tkinter RMRC State machines

Overview

MediSort simulates a coordinated workflow involving Ryan's robot, Flynn's robot and a UR3. The robots collect pills from known locations, transfer them between work areas and deposit them at their destination.

A Tkinter interface lets the user select a patient and operation mode, start actions, monitor progress and trigger an emergency stop. The robots and environment meshes are displayed in the Swift simulation environment.

System architecture

The Tkinter interface sends commands to the main application controller. The controller initialises the robots, pill shelf and environment, then coordinates each robot's movement module.

  • Main controller: manages setup, robot actions, state transitions and GUI updates.
  • Robot controllers: operate Ryan's robot, Flynn's robot and the UR3.
  • Movement modules: provide RMRC, positioning, end-effector orientation and gripper actions.
  • Swift environment: simulates the robots, obstacles, pill shelf and other STL meshes.

Pill handling sequence

The main loop processes each pill through a sequence of states:

  1. Approach: move toward the pill using RMRC.
  2. Level: adjust the end-effector orientation.
  3. Pick up: move into position and close the gripper.
  4. Handoff: move to the transfer location and coordinate with the UR3.
  5. Transfer: coordinate the next robot's pickup.
  6. Deposit: place the pill at its destination.
  7. Reset: return the robots to safe positions before processing the next pill.

Control and safety logic

Background threads keep the simulation responsive while robot actions run. Events coordinate pause and stop behaviour, and a queue passes progress updates to the GUI. Separate collision modules support obstacle and safety checks.

The interface also includes emergency-stop and teach-mode controls for interacting with the simulated system.
